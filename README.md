# e-plantShopping — Paradise Nursery Shopping Application

A simple online plant shop built with React and Redux Toolkit. The e-plantShopping application lets users browse houseplants, add plants to a shopping cart, change quantities, and view the total cost.

## Features
- Landing page with Get Started and About Us.
- Two plant categories with images, names, descriptions, and prices.
- Add to cart buttons that become disabled after adding a plant.
- Navigation with the total cart quantity.
- Cart with quantity controls, delete buttons, subtotals, and a total.
- Continue Shopping and a coming-soon Checkout message.

## Run

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
```

Cart data resets on page refresh. Checkout is a demonstration; it does not take payments. Plant images are hosted externally.
